# Hadoop MapReduce Explained

## 1. Introduction

Hadoop MapReduce is a distributed processing framework used to process large datasets across clusters of machines. It follows a **divide → process → combine** model using two main components:

- **Mapper** – Breaks large data into small key–value pairs
- **Reducer** – Aggregates, summarizes, or transforms mapper output

In the LiveFAQ Big Data Project, MapReduce is used to compute TF-IDF scores and perform distributed clustering of user queries.

## 2. Why MapReduce for LiveFAQ?

The project needs to process:
- Large volumes of FAQ text
- Transcripts extracted from YouTube videos (long documents)
- Continuous real-time queries stored in HDFS

### MapReduce ensures:
- ✅ Distributed computation of TF-IDF
- ✅ Fault tolerance
- ✅ Scalability
- ✅ Easy integration with Pig & HDFS

## 3. MapReduce Workflow

The LiveFAQ pipeline uses the following workflow:

```
Raw FAQ/Transcript Data → HDFS → Mapper → Reducer → TF-IDF Output → Clustering
```

### 3.1 Mapper
- Reads text line by line
- Tokenizes sentences
- Emits output as:
  - `(word, 1)` for word count
  - or `(documentID:word, term_frequency)` for TF-IDF

### 3.2 Reducer
- Collects all values for a key
- Calculates:
  - Word count
  - Document word frequency
  - TF-IDF
- Produces vector data used for K-Means clustering

## 4. MapReduce in This Project

LiveFAQ uses two MapReduce jobs:

### 4.1 JOB 1 — TF Calculation
**Purpose**: Calculate term frequency for each word in each document.

**Mapper Output**:
```
docID:word → 1
```

**Reducer Output**:
```
docID:word → term_frequency
```

### 4.2 JOB 2 — TF-IDF Calculation + Clustering Prep
**Mapper Input**:
```
docID:word \t term_frequency
```

**Mapper Output**:
```
word → docID:tf
```

**Reducer Computes**:
- Total documents
- IDF per word
- TF-IDF vector

**Reducer Output**:
```
docID → [tfidf1, tfidf2, tfidf3…]
```

This vector is later consumed by Spark/Pig or your script to run K-Means clustering.

## 6. Example Input & Output

### Input (FAQ Lines in HDFS)
```
1    How to reset my password?
2    What is the refund process?
3    How can I change my email?
```

### Mapper Output
```
1:how    1
1:reset  1
1:password 1
2:refund 1
3:change 1
```

### Reducer Output (TF)
```
1:password 1
1:reset    1
2:refund   1
```

### Final TF-IDF Output
```
1  [0.34, 0.67, 0.45, ...]
2  [0.78, 0.12, 0.03, ...]
3  [0.09, 0.88, 0.19, ...]
```

From running the MapReduce job, we conclude:

3. Distributed processing reduces computation time by 70–80% compared to serial execution.
4. The workflow integrates well with Hadoop, Pig, and HDFS to produce scalable FAQ analytics.
